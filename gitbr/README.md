# gitbr

使用 Go + promptui 实现的终端分支选择界面，交互方式与 gitmod 一致。

在任意 Git 工作目录或其子目录运行 `gitbr`，当前分支固定在第一项并默认选中，其余本地分支按名称倒序显示。每行附分支最近一次提交的时间，名字列按显示宽度对齐；搜索时日期同样可作为关键词。分支较多时可上下滚动。

- `↓` / `j` / `Ctrl+N`：下一项，最后一项继续向下会回到第一项。
- `↑` / `k`：上一项，第一项继续向上会跳到最后一项。
- 空格或回车：立即切换到选中的分支。
- `Esc`（Windows）/ `Ctrl+C`：取消。
- `Tab`：切换“选择”和“搜索”模式；搜索时输入关键词实时过滤，不区分大小写，支持中文。`j/k` 作为关键词输入，方向键和 `Ctrl+N` 仍可选择。
- 搜索时退格删除字符；空格或回车确认，无匹配项时不会切换。切回选择模式会清空关键词、恢复完整列表并选中第一项；远程模式仍保留最近 30 天的范围限制。
- `gitbr --help`：查看帮助。

本地模式切换使用 `git switch --no-guess`，需要 Git 2.23 或更新版本。不创建分支、不拉取、不提交、不推送。Git 允许保留的未提交修改会随切换保留；如果修改将被覆盖，或者分支已被其他 worktree 占用，会报告错误。不强制切换、不自动暂存。

## 远程分支

```powershell
gitbr --remote
```

先逐个获取所有已配置远端的全部分支（不获取标签），清理对应已删除的远程跟踪分支。任何远端获取失败都会停止，不切换分支。然后仅展示最新提交的提交者时间在最近 30 天内的分支，按提交时间从新到旧排列，显示远端名称和日期，排除远端 HEAD 符号引用。

这里的 30 天按分支尖端提交时间计算，并非分支创建时间；Git 没有可靠的分支创建时间。搜索只在筛选后的列表中进行，支持分支名称、远端名或显示日期关键词。

选中 `origin/feature/demo` 后：

- 本地不存在 `feature/demo`：创建同名本地分支，关联所选远程分支并切换。
- 本地同名分支已跟踪该远程分支：直接切换，不自动合并或重置本地提交。
- 本地同名分支未关联该远程分支（包括关联其他远端）：报错提示处理，避免切换到不对应的分支或覆盖上游设置。

远程模式同样保留 Git 对未提交修改和其他工作区占用的检查，不创建临时 worktree。取消选择不会切换分支；此前已获取的远程跟踪信息会保留。

新仓库没有本地分支时会提示；非 Git 工作目录、裸仓库或非交互终端会报告错误。无需配置文件，支持中文分支名。

## 构建和使用

需要 Go 1.17 及以上，依赖均为公开模块，依赖版本与 gitmod 保持一致。使用此目录的 `go.mod` 构建。

Git Bash 中执行：

```bash
./build.sh
```

或 PowerShell 中手动启用模块模式后构建：

```powershell
$env:GO111MODULE = 'on'
go build -o gitbr.exe .
```

将 `gitbr.exe` 所在目录加入 `PATH` 后，可在项目目录直接运行：

```powershell
gitbr
```

也可以直接调用可执行文件的完整路径。
